# Contributing to CloudGrid CLI

Thank you for your interest in contributing.

## This repository

This is the distribution repo for CloudGrid CLI. It contains the installer
script, documentation, and CI workflows. It does not contain CLI source code.

## Reporting issues

Open an issue at [cloudgrid-io/cli/issues](https://github.com/cloudgrid-io/cli/issues).
For security vulnerabilities, see [SECURITY.md](./SECURITY.md).

## Pull requests

Contributions to `install.sh`, documentation, and CI are welcome.

1. Fork the repository and create a branch.
2. Make your changes.
3. Run `shellcheck install.sh` if you modified the installer.
4. Open a pull request against `main`.

All pull requests require at least one approval and passing CI checks before
merging.
